# Fonts

The app uses the two fonts of the owner's other projects (SliceFX, danielford.io):

| File | Used for | Licence |
|---|---|---|
| `Manrope-Medium.ttf` | labels, numbers, body text | SIL Open Font License 1.1 (`Manrope-OFL.txt`). Included in this repo. |
| `NeueMachina-Medium.ttf`, `NeueMachina-Regular.ttf` | headings, tabs and buttons (uppercase) | **Neue Machina by Pangram Pangram, a commercial font.** NOT included in the public repo (git-ignored). |

If the Neue Machina files are missing, the app falls back to Manrope for headings, so nothing breaks.
To get the headings in your own checkout, copy `NeueMachina-Medium.ttf` here (for example from SliceFX's `assets/fonts`). Never commit or publish it unless your licence covers that.
